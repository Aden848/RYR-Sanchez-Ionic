# Guion del video — AP3_EquipoX.mp4 (2 min, máximo 3)

Hay que grabar la pantalla del emulador (o del celular) con voz. Al menos 1 integrante aparece hablando y se presenta a todo el equipo.

| Tiempo | Qué mostrar | Qué decir (sugerencia) |
|--------|-------------|------------------------|
| **0:00–0:30** | Cámara con el equipo (o foto + voz). Luego el login de la app. | "Somos el equipo X: [nombres]. Nuestra app es **R Y R Sánchez**, un sistema para gestionar clientes y préstamos." Iniciar sesión. |
| **0:30–1:30** | **Las 3 interfaces** (unos 20 s cada una) | **Panel:** tarjetas de totales, lista de préstamos en curso, FAB abierto. **Clientes:** buscar un nombre, lista con avatares, FAB → crear un cliente. **Préstamos:** cambiar el filtro (Activos / Atrasados), barra de cuotas, *Registrar pago*. |
| **1:30–2:30** | **Los 4 gestos** (unos 15 s cada uno) | (1) **Swipe:** en Clientes deslizar a la izquierda → Eliminar → tocar *Deshacer*. (2) **Pull-to-refresh:** jalar hacia abajo y mostrar la hora de "última sincronización". (3) **Pinch:** Préstamos → *Ver pagaré* → ampliar con 2 dedos (en el emulador, Ctrl + arrastrar), mover la imagen, doble toque para restablecer. (4) **Long-press:** mantener presionado un cliente → menú contextual → *Ver préstamos*. |
| **2:30–3:00** | **Menú lateral** | Abrir con ☰ y también deslizando desde el borde. Mostrar el encabezado, los iconos y la opción resaltada. Luego cambiar a vista **tablet** para mostrar el **split-pane** con el menú fijo. Cierre: "Gracias". |

Consejos: practiquen una vez antes de grabar. Tengan los datos sin borrar al empezar (si borran algo, recarguen la app). Graben en horizontal si van a mostrar el modo tablet.
